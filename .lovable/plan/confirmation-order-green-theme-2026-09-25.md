# Confirmation Order Green Theme

## Scope
- Update only the Confirmation Order preview and printable document styling.
- Preserve Offer Letter and Appointment Order styling, content, fields, and behavior.

## Changes

- Style the candidate summary and confirmation reference details with pale-green fills and green grid lines.
- Give every numbered section a solid green title bar and matching bordered content box.
- Add exact print color adjustment rules so backgrounds and borders remain visible in print/PDF output.

## Validation
- Confirm the Confirmation Order preview uses the new theme.
- Confirm Offer and Appointment documents remain visually unchanged.
- Check the app build status after the update.
